# Nouvelle identité Auto Miner

Une pioche cyan au manche cuivre frappe un bloc de minerai sombre. La bannière
reprend ce symbole dans un tunnel, avec un titre large et un seul sous-titre.
Elle ne contient pas de numéro de Minecraft qui pourrait devenir obsolète.

| Usage | Fichier |
| --- | --- |
| Logo PNG transparent, ressource source du mod | `src/main/resources/assets/autominer/textures/logo.png` |
| Icône web / Modrinth, export WebP léger | `site/assets/logo.webp` |
| Bannière PNG 2172 × 724 (3:1) | `site/assets/banner.png` |
| Bannière web, export WebP léger | `site/assets/banner.webp` |

Le logo est déclaré dans les trois `fabric.mod.json`, apparaît dans Mod Menu et
est dessiné dans l’en-tête de la configuration. Le site copie aussi le PNG source
pour garder une version téléchargeable cohérente. Les exports WebP ne changent ni
la composition ni les dimensions des visuels et conservent la transparence du logo.

Les illustrations sont des visuels de marque, pas des captures de gameplay.
